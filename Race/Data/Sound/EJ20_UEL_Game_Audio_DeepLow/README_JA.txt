EJ20風・不等長ボクサー排気音 / 低回転のボコボコ音を低くした版

前回の重低音版（BASS）を元に加工。
・アイドリング約950rpm、低回転約2200rpmの排気パルスについて、
  高く聞こえやすい100Hz付近と200〜500Hz付近の共鳴成分を抑制。
・50〜80Hz付近を補強して、より低く太いボコボコ感に調整。
・加速と減速も2200rpm以下は同じ処理を適用し、3900rpmまで滑らかに戻す。
・中回転4000rpm・高回転6500rpmループは前回版と同じ音色。

注：再生速度・エンジン回転数・長さは変更していません。
    高い共鳴成分の音量を抑えて低い成分を強調する音色加工であり、
    発火周期そのものの音程変更ではありません。

形式：WAV / 48,000Hz / 16bit PCM / モノラル
固定回転数の4種はループ用、加速と減速は単発演出用。

収録物は元の合成音に基づくゲーム用素材です。実車EJ20の録音ではありません。
